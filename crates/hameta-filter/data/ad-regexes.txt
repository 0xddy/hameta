# 广告 / 推广正则：命中后仅从标题中删除（比固定短语更灵活）
# 一行一条 Rust regex；# 开头为注释

# 2025年04月大神BT最新域名 / BT最新地址 等
(?i)(?:\d{4}年\d{1,2}月(?:\d{1,2}日)?\s*)?(?:大神)?BT最新(?:域名|地址|网址)
# 社群号与频道引流标签
(?i)[\[\(【]\s*(?:(?:QQ|Q|微信|VX|V信|TG|Telegram|电报)(?:群|频道|号)\s*[:：]?|(?:QQ|微信|VX|V信|Telegram|电报)\s*[:：])\s*[A-Za-z0-9_@\-]{4,24}\s*[\]\)】]
# 中文发布站点方括号推广标签
【[^【】]{0,24}(?:地址发布|最新地址|最新域名|独家首发|影视网|资源网|电影网|字幕网|论坛首发|福利群)】
# 公众号 / 关注引导括号标签
(?i)[\[\(【]\s*(?:关注)?(?:公众号|微信号|微信|VX|TG频道)\s*[:：]\s*[^\]\)】]{1,24}\s*[\]\)】]
# 带冒号跳转的备用/防屏蔽地址前缀或后缀
(?:第\d+备用|最新|永久|防屏蔽|防走丢)(?:地址|域名|网址)(?:发布页?)?(?:\s*[:：]\s*\S+)?
# 括号内邮箱联系方式引流
(?i)[\[\(【][^\]\)】]{0,16}[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,12}[^\]\)】]{0,16}[\]\)】]
